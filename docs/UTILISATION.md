# Utilisation quotidienne

## Vérifier la configuration

Après le démarrage, ouvrez **Diagnostic**. Avant toute écriture, assurez-vous que le vault est prêt, que les outils nécessaires sont disponibles et que l’écriture est autorisée localement.

## Ajouter une vidéo

1. Ouvrez **Ajouter** et saisissez une URL de vidéo publique.
2. Inspectez les pistes détectées et choisissez la source de transcription.
3. Vérifiez le transcript avant de poursuivre.
4. Préparez l’analyse ou un import.
5. Consultez la Preview, les opérations et les différences.
6. Confirmez l’ajout avec sauvegarde seulement si le résultat convient.

## Utiliser la file

La vue **File** accepte une URL par ligne et traite l’inspection à concurrence de un. Elle signale les doublons et permet de mettre en pause, reprendre, annuler ou réessayer un élément. Chaque vidéo continue toutefois dans son workflow individuel pour la transcription, la vérification et l’écriture.

## Retrouver les connaissances

Utilisez la bibliothèque pour parcourir les documents, la recherche pour retrouver un titre, un chemin ou un passage, et la vue de question pour obtenir des réponses accompagnées de citations. Vérifiez toujours les sources citées dans le Markdown original.
